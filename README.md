# Project Gallery
An application for displaying and managing projects.
## Description
This application is React - based that displays current accomplished projects and also one can add a new project to the list of projects.  
It also has a search feature, meaning user can search for the project to avoid time wasting while looping all over the cards.  
## Features
- Display projects in card.
- Search projects by title.  
- Add new projects.  
- Display project's description and technologies in each project card.  
## Technologies
- React
- JavaScript
- Tailwind css
- Vite
## Installation
1. Clone the repository.
2. Navigate into the project directory.
3. Install the dependencies.
4. Start the development server.  
```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```
